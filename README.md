\# Password Strength Checker



\## Project Overview

The Password Strength Checker is a Python-based cybersecurity project that evaluates password strength by checking different security criteria.



It helps users understand whether a password is weak, medium, or strong based on basic password security practices.



This project was developed as part of the SAM AI Technologies Cyber Security Internship.



\## Features

\- Checks minimum password length.

\- Checks for uppercase letters.

\- Checks for lowercase letters.

\- Checks for numbers.

\- Checks for special characters.

\- Displays password strength as WEAK, MEDIUM, or STRONG.

\- Provides feedback on missing security requirements.



\## Technologies Used

\- Python 3

\- String Handling

\- Conditional Statements

\- Regular Expressions



\## How to Run



1\. Install Python 3.

2\. Clone or download this repository.

3\. Open PowerShell in the project folder.

4\. Run:



```bash

python password\_strength\_checker.py

```



\## Password Security Criteria



The program checks whether a password contains:



1\. At least 8 characters.

2\. At least one uppercase letter.

3\. At least one lowercase letter.

4\. At least one digit.

5\. At least one special character.



\## Learning Outcomes

\- Understanding basic password-strength assessment.



\## Security Note

This project provides a basic password-strength assessment. It does not check passwords against leaked-password databases or guarantee protection against attacks.



Avoid entering real or sensitive passwords into demonstration programs.
